## 02 — Design System: Typography

The type system was built around two typefaces: a classical text face for body copy and footnotes, and a contemporary display face for headings, pull quotes, and section markers. The scale was developed using a modular ratio, ensuring consistent hierarchy across all text levels.

[Image: Type Scale / Specimen — ../images/thesis-book/type-scale.jpg]
[Image: Body Text Specimen]
[Image: Heading Hierarchy]

Particular attention was paid to footnote typography — a frequently neglected element in academic publishing. The footnote system uses a smaller size but maintains the same x-height ratio, ensuring notes read as related but subordinate to the main text.

---

## 03 — Design System: Grid & Layout

The grid system uses a six-column structure on a spread, with a generous outer margin for annotations and a narrower gutter. This asymmetric approach creates visual tension that keeps the reader engaged across long passages of text.

[Image: Grid Diagram & Layout Rules — ../images/thesis-book/grid.jpg]

Four layout templates handle the main content types: full-text spreads, image-heavy spreads, chapter openers, and end matter. Each template was designed to feel coherent with the others while serving its specific content function.

---

## 04 — Visual Language: Color, Motifs & Image Style

The color system is restrained: a warm off-white stock, a single accent color derived from the thesis subject matter, and black. Images are treated with a consistent duo-tone effect that ties them visually to the text.

## 05 — Process: Iterations & Type Tests

The design went through three significant iterations before reaching its final form. Early layouts were rejected for being too sparse; a mid-process version was too decorative. The final system found its balance in the third iteration — confident but never showy.
